
## Problem: Two Sum (Easy)

**Link:** https://leetcode.com/problems/two-sum/

### Approach
I used a nested loop to check each pair of elements in the array. If the sum of two elements equals the target, I return their indices.

### Complexity
- Time: O(n²)
- Space: O(1)

### Notes
The solution returns the indices of two numbers whose sum equals the target. The same element cannot be used twice.
